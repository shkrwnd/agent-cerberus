Agent security infrastructure

Claude Code, securely jailed.

Claude Jail runs AI coding agents inside a hardened Docker container while sensitive CLI operations are authorized and executed by a trusted host-side broker. Credentials never enter the container.

View on GitHub Read the architecture Security model

Zero guest credentials

Cloud, GitHub, and infrastructure secrets remain on the trusted host.

Policy-controlled commands

Broker git, aws, gh, kubectl, terraform, psql, and other CLIs through pluggable authorization.

Restricted egress

An allowlisted HTTPS proxy blocks arbitrary outbound connections from the agent.

Auditable execution

Record authorized commands, decisions, outputs, and exit status outside the container.
