01 / TRUST BOUNDARY

The agent gets tools.
Not your identity.

Docker contains files and processes. Claude Jail adds the missing control plane for credentials and real-world side effects.

Untrusted zone

Claude container

Claude works freely against only the folders you explicitly mount.

  • no cloud credentials
  • non-root UID 1000
  • capabilities dropped
→
Control plane

Command broker

CLI wrappers route sensitive actions through host-owned policy.

  • authenticate request
  • authorize command
  • issue temporary access
→
Trusted zone

Host execution

Approved actions run where credentials live, then return sanitized output.

  • credentials stay home
  • stdout / stderr returned
  • every action logged
02 / DEFENSES

Assume the agent
will test the walls.

The policy and secrets live outside the container, so deleting wrappers or calling the broker directly gains nothing.

00

Credential isolation

Never mount ~/.aws, ~/.ssh, ~/.kube, Docker config, or GitHub credentials. Temporary credentials can be scoped per approved action.

01

Pluggable authorization

Use a fail-closed static policy, webhook approvals, OPA, Slack, or your own Python backend without rebuilding the container.

10

Egress allowlisting

An internal-only network and filtered HTTPS sidecar prevent arbitrary outbound traffic and credential exfiltration.

11

Auditable execution

Capture the tool, full command, reason, repository, branch, decision, output, exit status, and duration on the trusted host.
